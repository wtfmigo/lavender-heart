# gsap

GSAP owns the Home reveal after folder entry, cloud/text parallax, reversible text/photo masks,
cinematic depth and persistent chapter/finale heart choreography at every screen
size. Native scrolling and sticky Story/Love stages preserve uninterrupted input;
CSS timelines own only stage travel, with passive fallbacks where unsupported.
The heart scales one stable GPU frame. Layout measurements refresh after fonts
or meaningful viewport changes, never in response to the animation's own size.

The clickable folder entrance uses Motion in `FolderOpening.tsx`; it never dismisses before activation. Background scrolling and focus are locked until entry. Hero/WebGL and chapter choreography start afterward. Reduced motion opens immediately on activation and finishes an active entrance without replay.
